# huntkit ist eine private App und soll in keinem Suchergebnis auftauchen.
#
# Dafür trägt jede Seite ein <meta name="robots" content="noindex, nofollow">
# und jede Antwort des Servers den Header X-Robots-Tag. Damit eine Suchmaschine
# das lesen kann, muss sie die Seite abrufen dürfen – ein pauschales
# "Disallow: /" würde genau das verhindern und die nackte Adresse trotzdem im
# Index landen lassen. Suchmaschinen dürfen also herkommen und bekommen dann
# das noindex zu sehen. Nur der Gruppen-Server hat für sie nichts.

User-agent: *
Allow: /
Disallow: /api/
